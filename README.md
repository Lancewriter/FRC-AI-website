# FRAICLY - Financial Risk Consultants AI

A modern, responsive website for FRAICLY, a financial risk consulting firm specializing in AI-powered solutions for small and medium-sized enterprises (SMEs).

## Project Structure

```
├── index.html          # Main HTML file
├── styles.css          # CSS stylesheet
├── scripts.js          # JavaScript functionality
├── style.css           # Legacy CSS (kept for reference)
├── netlify.toml        # Netlify deployment configuration
└── assets/             # Image assets
    ├── FRAICLY.jpg
    ├── AI logo.jpg
    ├── fortune 500.jpg
    ├── mission.jpg
    ├── Ownership.jpg
    └── ... (other images)
```

## Features

### 🎯 **Modern Design**
- Clean, professional HTML5 structure
- Responsive CSS3 with modern flexbox and grid layouts
- Mobile-first responsive design
- Accessible navigation and interactive elements

### 🧭 **Navigation**
- Sticky header with smooth scrolling
- Desktop and mobile navigation menus
- Dropdown menus for sectors and services
- Mobile hamburger menu

### 🎨 **Hero Section**
- Eye-catching hero section with video integration
- Clear value proposition
- Call-to-action buttons
- Fully responsive across all devices

### 💬 **Interactive Chatbot**
- Fixed-position chatbot widget
- AI-powered responses based on keywords
- Smooth animations and transitions
- Mobile-optimized interface

### 📱 **Responsive Design**
- Mobile-first approach
- Breakpoints for tablet and desktop
- Optimized for all screen sizes
- Touch-friendly interface elements

### ⚡ **Performance**
- Separated CSS and JavaScript files
- Optimized code structure
- Fast loading times
- SEO-friendly markup
